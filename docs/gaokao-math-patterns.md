# 新高考Ⅰ卷数学命题规律（工作版）

Last reviewed: 2026-07-12

## 使用原则

这份规律用于题库覆盖检查、难度先验和变式审核，不是押题表。题号有稳定倾向，但命题人会调整顺序、融合知识点和更换情境。系统只能把规律作为先验，不能写成“第几题必考什么”。

## 试卷的稳定骨架

- 2020—2023 新高考Ⅰ卷通常为 22 题；2024 起为 19 题。题型结构和分值必须随 `ExamProfile` 版本保存。
- 前段客观题更常检查复数、集合、函数基本性质、向量、三角等主干概念。复数和集合常靠前，但不保证固定为第1、2题。
- 同一客观题型内，位置越后通常综合度和区分度越高；这是难度先验，不替代人工审题和学生实测。
- 多选题更适合考性质辨析、多个结论同时判断和信息整合；填空题更适合结果明确、表达较短但需要运算或转化的内容。

## 解答题的高频模块

近年来解答题长期围绕以下主干轮换与组合：

1. 数列、三角函数或解三角形：常承担相对可进入的前段解答题，强调公式选择、递推/通项、恒等变换和规范计算。
2. 概率与统计：适合用真实情境承载数据处理、概率模型、分布或统计推断。设问通常从读懂模型到计算和解释逐步推进。
3. 立体几何：天然需要画图、证明空间位置关系、计算角或距离，更适合作为有过程分的解答题；小题出现数量少并不代表模块不重要。
4. 解析几何与圆锥曲线：常通过直线与曲线的位置关系、定点定值、范围或证明形成较长推理链。
5. 导数及其应用：常用于函数单调、极值、零点、不等式或参数分类，重视分类完整性和数学表达。

这五类并非每年严格各占一道。数列可能与概率、函数结合，立体几何可能使用空间向量，解析几何和导数的先后及难度也会变化。系统应检查一套训练是否覆盖能力结构，而不是机械复制模块数量。

## 对题库和组卷的约束

- 立体几何不能因小题少而被判定为题库缺口已小；应单独检查解答题和评分细则数量。
- 客观题不集中抽取各地试卷的末题；解答题也不能全部选择圆锥曲线、导数的最后设问。
- 模块覆盖与难度分开控制：一道基础导数题不应自动比一道综合概率题更难。
- AI变式应先选定基题，再说明改变的参数、条件、设问或综合点，并保持 `parentQuestionId`。
- AI变式只进入 `candidate`；独立解题、查重和人工审批后才能 `published`。

## 对准高二学生的训练含义

- 已学范围可以逐步覆盖数列、直线与圆、圆锥曲线、计数原理和导数，但不能把所有训练都做成各模块最末题。
- 默认标准训练保留约30%的较易题、50%的核心题和20%的提升题；纯记忆型常数题不进入默认自动选题。
- 解答题训练优先看“能否拿到前两问和过程分”，再逐步增加最后一问的开放性与综合度。

## 证据边界

本地结构化库对部分年份和题号的拆分仍不完整，不能据此声称精确频率。当前文档结合本地原卷人工观察与教育部公开命题评价所强调的基础性、综合性、应用性、创新性和主干知识形成。后续应在 2020—2026 全国Ⅰ卷完整逐题入库后生成按题号、模块、能力和难度的版本化统计。
