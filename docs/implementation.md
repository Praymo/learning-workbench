# Learning Workbench

一个运行在本机的高中数学学习工作台。它把一条容易被拆散的学习闭环放在同一个界面里：从已核验的题目生成有训练目的的练习，打印后用纸笔完成，再确认录入或识别到的答案，最后把可确认的结果用于错题复查和知识点记录。

这个项目服务一个本地学习者，不是班级管理、在线作业、排行榜或账号系统。它的重点也不是“用模型代替老师批改”，而是把题源、题目质量、选题理由、人工确认和评分证据串起来，让每一步都能回看。

## 一个真实使用场景

学习者今天想解决的是“会做但容易丢分”，在练习页选择“客观题稳定训练”、已学范围、训练强度和时间预算。系统只从 `published` 题目中选题，同时避开最近三套练习中的题、内容/参数近重复和同一模型的过度重复，并把选题数量、排除原因和题库缺口留在练习单里。

练习可以切换成学生版或答案解析版并按 A4 打印。完成纸笔作答后，在批改答卷页选择对应练习；客观题可以不上传照片，直接进入答案确认。若使用照片，识别文本仍可编辑，确认之前不会评分。单选、多选和可判定的填空由本地规则处理；解答题只有在评分细则完整且配置了模型时才给出逐评分点建议，否则保留“需要人工确认”。

确认后的分数才会进入本地学习证据。错题第一次安排三天后复查，连续两次复查正确才标记稳定；知识点掌握度采用透明的 `weighted-v1` 规则，并在证据少于三条时明确显示“证据不足”。维护者可以在维护中心浏览来源、导入结构化真题、审核 OCR 和检查题目质量，但这些工具不出现在学习者的日常主导航中。

## 当前实现

- Next.js 15、React 19、TypeScript、Prisma 6 和 SQLite；数据默认只落在本机。
- 四种题型：单选、多选、填空和解答题。只有答案、解析和审核状态满足门槛的题目可以组卷。
- 题库浏览、关键词/年份/卷型/来源/知识点/难度/审核状态筛选，题目详情和编辑发布流程。
- 三种练习目的：客观题稳定、解答题过程分、迁移与综合。组卷记录目标、已选题和排除原因。
- 学生版/答案版练习单和 A4 打印样式。
- 多张答卷照片上传、可编辑 OCR 确认、无视觉模型时的人工录入回退，以及本地客观题评分。
- 填空答案对分数、小数、根式、代数式、集合、区间和多空形式做有限等价判断；无法可靠判断时进入人工复核。
- 解答题评分点、证据文本、顺错给分和人工确认状态；模型调用使用任务、Prompt 版本和输入哈希缓存。
- 题源 PDF/结构化数据的来源追溯、质量指纹、原卷页和拆题草稿边界。
- 专题总结、分层变式、方法选择树、错题复查和可解释掌握档案。

## 产品取舍

题库优先意味着“可用题少一些”可以是正确结果：缺答案、缺解析、图像或题目边界不可靠的记录不会为了凑数量进入练习。练习选择使用原卷位置作为初始难度先验，但没有把它写成学生实测难度。模型只负责结构化识别或给出可审核建议，不能越过人工确认直接发布题目、记录过程分或改变正式答案。

本项目保留来源和审核状态，是为了让学习反馈可以追溯到题目证据；同时只做本地单用户数据存储，避免在当前阶段引入账号、班级、云端同步和不必要的个人档案。

## 安全演示启动

发布副本不包含数据库、原卷、上传图片、模型缓存、`.env` 或本机常驻服务配置。请在副本目录执行：

```bash
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed
npm run questions:foundation
npm run questions:high-one-core
npm run topics:seed
npm run dev:local
```

打开 <http://127.0.0.1:3006/>。上述种子只写入本地合成/人工整理题目；`.env` 中的模型变量留空时，题库、组卷、打印、人工答案确认和客观题评分仍可用。为了演示评分链路，请在“批改答卷”里选择一套练习、保持照片为空、勾选“测试模式”，这样确认后的结果不会写入错题队列或掌握档案。不要把真实答卷、学生照片、学校资料或真实 API 密钥放进这个仓库。

如果只想检查构建，可以运行：

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

`typecheck` 使用项目默认的增量配置；在只读文件系统中可改用 `npx tsc --noEmit --incremental false`。

## 已知边界

- 没有登录、权限、多用户、班级、在线部署或云端长期记忆；当前设计假定站点只监听本机。
- 仓库内没有视觉模型密钥，真实 OCR 和解答题模型评分需要使用者自行配置兼容接口，并仍要人工确认。
- 当前填空等价判断覆盖常见形式，不能替代所有数学等价证明；复杂或不支持的表达会要求复核。
- 解答题评分细则仍需逐题核验，不能宣称等同正式考试阅卷。
- 原卷和模拟卷的版权、使用条件、图像裁切和题目边界仍需人工审核；公开副本只保留导入/追溯代码，不携带下载的题源文件。
- 生产常驻服务脚本未放入公开副本，因为它依赖个人机器路径；本地开发启动是可复现的演示入口。

## 目录

- `src/app`：学习者页面、维护页面和 API 路由。
- `src/lib`：组卷、题库质量、数学等价判断、OCR/模型接口、评分、证据和错题规则。
- `prisma`：SQLite 数据模型与迁移。
- `scripts`：初始化、种子、来源同步和质量处理命令。
- `tests`：题型、数学渲染、组卷、防重复、评分点、来源匹配、专题和错题状态测试。
- `docs`：项目状态、题源政策和历史问题记录。
